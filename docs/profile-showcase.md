## 千医 · ICD 智能病案编码

基于本地大语言模型的病案编码工程，覆盖病历 OCR / 结构化解析、疾病与手术操作编码、ICD 知识检索及业务管理。

- 技术栈：Vue 3、Django、Flask、PaddleOCR、Elasticsearch、本地模型服务。
- 工程特色：疾病 / 手术分支、多阶段模型处理、前后端服务编排、编码过程展示。
- 项目入口：[qianyi-icd](https://github.com/geekhall-lichuanlong/qianyi-icd)（当前私有，仅授权访问者可见）。
