## 千医 · ICD 智能病案编码

基于本地大语言模型的病案编码工程，覆盖病历 OCR / 结构化解析、疾病与手术操作编码、ICD 检索及业务管理。

- 技术栈：Vue 3、Django、Flask、PaddleOCR、Elasticsearch、本地模型服务。
- 工程特色：疾病 / 手术分支、多阶段模型处理、服务编排与编码过程展示。
